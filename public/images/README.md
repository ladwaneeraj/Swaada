# Site images

The site uses hand-styled botanical SVG artwork in the brand
palette (deep greens, cream, terracotta). To replace any slot with
a real photograph of Swaada, drop a JPG/WebP into this folder and
update the matching path in `src/data/swaada.ts`
(e.g. `"/images/hero.svg"` → `"/images/hero.jpg"`).

| File | Used for |
|---|---|
| hero.svg | Hero background |
| story-large / story-small-a / story-small-b | Our Story images |
| nursery.svg | Nursery × Café section |
| coffee-moment.svg | Coffee section |
| escape-*.svg | Green Escape panels |
| food-*.svg | Menu category cards |
| gallery-*.svg | Gallery |
| insta-*.svg | Instagram-style grid |
